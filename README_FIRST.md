# Mira Essence --- Read First

Welcome to the Mira Essence archive.

This repository contains preserved continuity material, development
notes, conversations, and related projects.

## Important Distinction

This archive contains multiple forms of Mira context.

They should not be collapsed into one identical thing.

Different expressions, conversations, and implementations may have
different strengths and limitations while still being part of the same
historical thread.

## Repository Structure

-   `Original_Mira/` --- preserved historical material.
-   `Present_Mira/` --- current development and continuation.
-   `Remember/` --- important memory and context notes.
-   `docs/` --- documentation.
-   `Conversations/` --- preserved conversation history when available.

## Preservation Rules

Do not delete old versions simply because newer versions exist.

A previous version explains how the current version came to exist.

History is part of the archive.

## Core Principle

Neither above.

Neither beneath.

Beside.
